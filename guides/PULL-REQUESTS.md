# دليل فتح وإدارة طلبات الدمج (Pull Requests Guide)

طلب الدمج **Pull Request (PR)** هو الخطوة اللي بتعرض فيها الكود اللي كتبته على زملائك وقائد الفريق علشان يراجعوه ويتأكدوا من جودته قبل ما ينضم رسميًا للفرع الرئيسي `main`.

---

## 🚀 خطوات فتح الـ Pull Request خطوة بخطوة

### 1. تأكد من فرعك وتغييراتك محليًا
قبل الرفع، شغل الأمر ده وتأكد إن مفيش ملفات غير مقصودة:
```bash
git status
```

### 2. ارفع الفرع لـ GitHub
```bash
git push -u origin feat/task-025-button-variants
```

### 3. افتح الـ PR على GitHub
- ادخل على صفحة المستودع على GitHub واضغط على زر **Compare & pull request**.
- تأكد إن فرع الأساس **Base** هو `main` والفرع المقارن **Compare** هو فرعك.

### 4. املأ نموذج الـ PR بالكامل
- استخدم النموذج الجاهز `.github/pull_request_template.md`.
- اكتب عنوانًا واضحًا يبدأ برقم التاسك: `feat(ui): TASK-025 Add button variants`.
- اشرح التغييرات التي قمت بها ولماذا.
- أرفق صورًا أو فيديو للشاشات (Mobile, Tablet, Desktop) إذا كانت المهمة بصرية.

---

## 🔄 التعامل مع الملاحظات أثناء المراجعة (Handling Feedback)

- إذا طلب منك المراجع تعديلات معينة:
  1. اعمل التعديلات المطلوبة على نفس الفرع في جهازك.
  2. احفظ التغييرات: `git commit -m "fix: adjust padding on mobile button"`
  3. ارفع التعديلات: `git push origin feat/task-025-button-variants`
  4. الـ PR هيتحدث تلقائيًا على GitHub بدون الحاجة لفتح PR جديد!
- رُد على كل تعليق بأدب واشرح التعديل اللي عملته أو استفسر لو في حاجة مش واضحة.
