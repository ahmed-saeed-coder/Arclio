# دليل HTML والمعايير الدلالية (HTML Guide)

لغة HTML هي الهيكل العظمي لصفحات الويب. في ARCLIO، بنركز على استخدام عناصر HTML الدلالية **Semantic HTML** لأنها بتخلي الموقع مفهوم لمحركات البحث ولمتصفحات ذوي الاحتياجات الخاصة **Screen Readers**.

---

## 🏗️ العناصر الدلالية الأساسية (Semantic Elements)

بدل ما تستخدم `<div>` في كل مكان، استخدم العنصر المخصص لوظيفته:

```html
<!-- الهيكل الدلالي القياسي لأي صفحة -->
<header>
  <nav aria-label="التنقل الرئيسي">
    <a href="/" class="brand-logo">ARCLIO</a>
    <ul>
      <li><a href="/explore">المشاريع</a></li>
      <li><a href="/paths">المسارات</a></li>
    </ul>
  </nav>
</header>

<main>
  <section class="hero-section">
    <h1>Learn. Build. Become.</h1>
    <p>منصة بناء المشاريع البرمجية الحقيقية.</p>
  </section>

  <section class="featured-projects">
    <h2>المشاريع المميزة</h2>
    <article class="project-card">
      <h3>بطاقة أسعار متجاوبة</h3>
      <p>تعلم كيفية بناء بطاقة أسعار باستخدام CSS Grid.</p>
    </article>
  </section>
</main>

<footer>
  <p>&copy; 2026 ARCLIO. جميع الحقوق محفوظة.</p>
</footer>
```

## 🎯 قواعد ذهبية في HTML (Golden Rules)

1. **تسلسل العناوين (Heading Hierarchy)**:
   - الصفحة لازم تحتوي على `<h1>` واحد فقط يمثل العنوان الرئيسي للصفحة.
   - استخدم `<h2>` للأقسام الرئيسية، و `<h3>` للعناوين داخل البطاقات؛ بلاش تنط من `<h1>` إلى `<h4>` مباشرة.
2. **الفرق بين الزر `<button>` والرابط `<a>`**:
   - **الرابط `<a>`**: للتنقل بين الصفحات وتغيير الـ URL (مثل الانتقال لصفحة المشاريع).
   - **الزر `<button>`**: لتنفيذ أكشن أو حدث في نفس الصفحة (مثل فتح نافذة منبثقة Modal، أو تبديل الثيم).
3. **النصوص البديلة للصور (`alt` attribute)**:
   - كل وسم `<img>` لازم يحتوي على خاصية `alt` تصف محتوى الصورة بوضوح لمستخدمي قارئات الشاشة.
