## هدف التعلم Learning Goal

## لماذا توجد هذه المهمة؟ Why This Task Exists

## الهدف Objective

## المتطلبات Requirements
- استيعاب نصائح المراجع: شرح 'لماذا'، مدح الأفكار الممتازة، والتفريق بين الملاحظات الجوهرية والـ Nitpicks.
- استيعاب نصائح صاحب الـ PR: تقبل الملاحظات، النقاش الإيجابي، وحل التعليقات بعد التعديل.
- الاطلاع على نموذج PR مفتوح وكتابة تعليق مراجعة تجريبي لزميل.
