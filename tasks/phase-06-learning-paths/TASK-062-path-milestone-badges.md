## المتطلبات Requirements
- فحص شرط `if (percentage === 100)` بعد كل تحديث للتقدم.
- إظهار وسام الإنجاز الذهبي `.badge-milestone-gold` وتفعيل زر 'عرض الشهادة'.
- إطلاق إشعار Toast احتفالي عند الوصول لـ 100% لأول مرة.
- حساب الوقت التقديري المتبقي بناءً على عدد الدروس غير المنجزة.

## متطلبات واجهة المستخدم UI Requirements
