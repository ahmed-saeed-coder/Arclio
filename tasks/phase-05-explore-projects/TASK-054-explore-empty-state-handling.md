## الهدف Objective

## المتطلبات Requirements
- فحص شرط `if (items.length === 0)` داخل دالة الرندرة.
- حقن هيكل الحالة الفارغة المتضمن أيقونة بحث فارغة وعنوان 'لم يتم العثور على مشاريع مطابقة'.
- إضافة زر داخل الحالة الفارغة يعيد تعيين البحث عند النقر عليه.
- التأكد من دعم التباين وسهولة القراءة.

## متطلبات واجهة المستخدم UI Requirements
