## الهدف Objective
إنشاء حاوية `.active-filters-bar` وتوليد رقاقات الفلاتر النشطة مع زر مسح الكل.

## المتطلبات Requirements
- إنشاء حاوية رقاقات الفلاتر النشطة أسفل شريط الأدوات.
- توليد رقاقة صغيرة لكل فلتر نشط (مثل: 'الصعوبة: مبتدئ ✖') مع زر حذف صغير.
- إضافة زر 'إعادة ضبط الفلاتر' الذي يمسح البحث ويعيد القوائم للوضع الافتراضي.
- إخفاء شريط الرقاقات تلقائيًا عند عدم وجود أي فلاتر نشطة.

## متطلبات واجهة المستخدم UI Requirements
رقاقات رمادية أنيقة بحواف دائرية تحتوي على أيقونة X صغيرة للحذف السريع.

## متطلبات التجاوب Responsive Requirements
شريط الرقاقات يلتف بسلاسة flex-wrap على الشاشات الصغيرة.

## متطلبات إمكانية الوصول Accessibility Requirements
توفير aria-label لكل زر حذف رقاقة (مثل: 'إلغاء فلتر الصعوبة').
