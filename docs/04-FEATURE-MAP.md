# 04 — خريطة الميزات وتوزيع المراحل (Feature Map)

الجدول ده بيصنف جميع ميزات منصة ARCLIO حسب المجال، المستخدم المستهدف، الأولوية، والمرحلة المحددة لتنفيذها.

---

## 📊 مصفوفة ميزات المنصة (Feature Matrix)

| مجال الميزة (Feature Area) | الإمكانيات والوظائف المحددة | المستخدم المستهدف | الأولوية | مرحلة التنفيذ (Phase) |
| :--- | :--- | :--- | :--- | :--- |
| **الهوية والصفحة الرئيسية** | هيدر دلالي Semantic Header، مساحة Hero، فوتر، وتصميم متجاوب Responsive | كل الزوار | P0 | Phases 00–02 |
| **نظام التصميم (Design System)** | متغيرات التصميم Tokens (ألوان، نصوص، مسافات)، أزرار، بطاقات، ونوافذ منبثقة | المطورون | P0 | Phases 01, 03 |
| **واجهة المستخدم التفاعلية** | زر تبديل الثيم الداكن Dark Mode، القائمة الجانبية للموبايل، وتنبيهات Toast | كل المستخدمين | P0 | Phase 04 |
| **استكشاف المشاريع (Explore)** | شبكة المشاريع، الفلترة حسب الصعوبة والتقنية، البحث المباشر، والمفضلة | المتعلمون | P0 | Phase 05 |
| **المسارات التعليمية (Paths)** | شجرة الدروس، خريطة الوحدات، وحفظ تقدم الطالب في `localStorage` | المتعلمون | P1 | Phase 06 |
| **مواصفات المشاريع (Briefs)** | متطلبات التذاكر، روابط تصاميم Figma، نموذج تسليم الرابط، ومعايير التقييم | المتعلمون والموجهون | P1 | Phase 07 |
| **محرر الأكواد التفاعلي** | محرر كتابة الكود داخل المتصفح، معاينة مباشرة Live Iframe، والتحقق الآلي | المتعلمون | P1 | Phase 08 |
| **لوحة تحكم الطالب (Dashboard)** | عداد الاستمرارية Streak، خريطة النشاط Heatmap، ومعرض الأعمال الشخصي | المتعلمون | P1 | Phase 09 |
| **معمارية الواجهة الأمامية** | وحدات ES Modules، ملفات JSON الثابتة، طبقة Fetch API، وإدارة الحالة | المطورون | P1 | Phase 10 |
| **الانتقال لأطر العمل (React)** | إعداد Vite + TypeScript، إعادة بناء المكونات بـ React 19، واختبارات Vitest | المطورون | P1 | Phase 11 |
| **الواجهة الخلفية (REST API)** | خادم Node.js/Express، التحقق من المدخلات عبر Zod، ومعالجة الأخطاء المركزية | كل المستخدمين | P1 | Phase 12 |
| **قواعد البيانات (Database)** | مخطط PostgreSQL، أداة Prisma ORM، إنشاء الجداول Migrations، والفهارس | كل المستخدمين | P1 | Phase 13 |
| **التوثيق والأمان (Auth)** | تشفير كلمات المرور، جلسات JWT/Cookies، الصلاحيات RBAC، وتسجيل الدخول بـ GitHub | كل المستخدمين | P1 | Phase 14 |
| **التكامل الشامل (Full Stack)** | ربط الواجهة الأمامية بالـ API الحقيقي، طابور المراجعة، والإشعارات الفورية | المتعلمون والموجهون | P2 | Phase 15 |
| **المجتمع والفرق (Community)** | ساحة النقاشات، مطابقة المراجعة بين الزملاء، ومساحات عمل الفرق Squads | المجتمع التقني | P2 | Phase 16 |
| **لوحة تحكم الإدارة (Admin)** | إدارة المناهج التعليمية، شاشة تقييم وتصحيح المشاريع، وسجل الإشراف | المشرفون والموجهون | P2 | Phase 17 |
| **هندسة الجودة (Quality & QA)** | اختبارات التكامل الشاملة Playwright، فحص إمكانية الوصول Axe، وتوافق المتصفحات | جودة المنصة | P0 | Phases 18–19 |
| **الإنتاج والعمليات السحابية** | أتمتة CI/CD عبر GitHub Actions، حاويات Docker، واستضافة سحابية Cloud Hosting | العمليات والإنتاج | P0 | Phase 20 |
