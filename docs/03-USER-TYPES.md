# 03 — أنواع المستخدمين وشخصياتهم (User Types & Personas)

فهمنا للمستخدمين واحتياجاتهم هو اللي بيوجه قراراتنا في تصميم واجهات وتجربة مستخدم منصة ARCLIO.

---

## 1. المطور المبتدئ / المتعلم (Junior Developer / Learner) — الشخصية الأساسية

### الملف الشخصي:
- **الاسم**: أحمد / سارة / محمد
- **الخلفية**: طالب حاسبات، خريج معسكر تدريبي **Bootcamp**، أو متعلم ذاتي **Self-taught**.
- **المستوى الحالي**: يعرف أساسيات HTML، بعض CSS، ومبادئ كتابة كود JavaScript.
- **الأهداف**: بناء مشاريع قوية لسيرته الذاتية **Portfolio**، فهم طريقة العمل بـ Git، واكتساب خبرة العمل الجماعي للالتحاق بوظيفة مطور برمجيات.
- **التحديات التي يواجهها**:
  - الارتباك والتشتت عند البدء في مشروع جديد من الصفر.
  - صعوبة فهم أدوات الـ Build المعقدة في بداية التعلم.
  - عدم وجود من يراجع الكود الخاص به ويوضح له الأخطاء.

### كيف تخدمه منصة ARCLIO:
- مهام برمجية مقسمة بعناية وبأهداف تعليمية واضحة ومحددة.
- مراجعات كود دورية وبناءة من الزملاء والمشرفين.
- معرض أعمال موثق يعرض الكود الحقيقي والمشاريع المنجزة.

---

## 2. قائد الفريق / الموجه الزميل (Squad Leader / Peer Mentor)

### الملف الشخصي:
- **الخلفية**: مطور متوسط أو متقدم يسعى لتطوير مهاراته القيادية ومراجعة الكود البرمجي.
- **الأهداف**: ترسيخ المعرفة البرمجية عبر تعليم الآخرين، وتوجيه فريق صغير من (3–5 مطورين).
- **المسؤوليات**:
  - توزيع المهام والتأكد من عدم وجود تضارب في العمل.
  - مراجعة طلبات الدمج **Pull Requests** وتقديم توجيهات تعليمية.
  - مساعدة المطورين المبتدئين في تجاوز العقبات البرمجية اليومية.

---

## 3. مؤلف المناهج والموجه المتقدم (Curriculum Creator / Mentor)

### الملف الشخصي:
- **الخلفية**: مهندس برمجيات محترف أو مدرب تقني.
- **الأهداف**: صياغة مواصفات مشاريع واقعية، وتحديد معايير التقييم **Rubrics** للمشاريع المتقدمة.
- **الاحتياجات**: أدوات تحرير مرنة، وطابور مراجعة وتقييم منظم لمشاريع الطلاب.

---

## 4. مدير المنصة (Platform Administrator)

### الملف الشخصي:
- **الخلفية**: مسؤول صيانة النظام وإدارة العمليات **DevOps**.
- **المسؤوليات**:
  - إدارة صلاحيات المستخدمين **Role-Based Access Control (RBAC)**.
  - مراقبة أمان المنصة، ومعدل استهلاك الـ API **Rate Limiting**، وضمان الالتزام بميثاق السلوك.
