# 08 — التوجه التقني وحزمة البرمجيات (Technical Direction)

المستند ده بيحدد خارطة التطور التقني لمنصة ARCLIO لضمان توافق الاختيارات البرمجية مع نمو مهارات الفريق وقابلية توسع المنصة.

---

## 🛠️ مراحل تطور حزمة التقنيات (Tech Stack Evolution)

```text
المرحلة الأولى: الأساسيات القياسية (Current: Phases 00–09)
Semantic HTML5 + Modern CSS (Custom Properties) + Vanilla JavaScript (ES6+)
                │
                ▼
المرحلة الثانية: المعمارية المعيارية (Phases 10–11)
ES Modules + Vite + TypeScript + React 19 Component Library
                │
                ▼
المرحلة الثالثة: الأنظمة المتكاملة المنفصلة (Phases 12–15)
Node.js / Express / NestJS REST API + PostgreSQL + Prisma ORM + JWT Auth
                │
                ▼
المرحلة الرابعة: هندسة الإنتاج السحابي (Phases 16–20)
Docker Containers + GitHub Actions CI/CD + Cloud Hosting + Playwright E2E
```

---

## 🎯 الأسباب المنطقية للاختيارات التقنية (Decisions & Rationale)

### 1. لماذا نبدأ بـ Vanilla HTML / CSS / JavaScript؟
- **وضوح المفاهيم البرمجية**: يحتاج المطور المبتدئ لفهم بنية الـ DOM، وسلوك تدفق الأحداث **Event Bubbling**، وتتالي التنسيقات **CSS Cascade**، والتعامل مع مصفوفات وكائنات JavaScript الأصلية دون تشتيت من أدوات الترجمة والـ Bundlers.
- **مهارات تدوم طويلاً**: أساسيات المتصفح ومعايير الويب القياسية تدوم لعشرات السنين بغض النظر عن تغير أطر العمل.

### 2. لماذا ننتقل إلى React و TypeScript في المرحلة 11؟
- **إعادة استخدام المكونات البرمجية**: مع تزايد عدد الصفحات وحالات الواجهة التفاعلية، تصبح كتابة مكونات React وإضافة الأنواع الصارمة بـ TypeScript أمرًا حاسمًا لمنع أخطاء وقت التشغيل **Runtime Errors**.
- **مواكبة سوق العمل العالمي**: تعتبر تركيبة React + TypeScript المعيار الأكثر طلبًا في وظائف هندسة الواجهات الأمامية.

### 3. لماذا Node.js و PostgreSQL في المراحل 12–13؟
- **لغة موحدة للمشروع بالكامل**: استخدام JavaScript/TypeScript في الواجهة الأمامية والخلفية يساعد المطور على تطبيق نفس المنطق البرمجي وبناء الـ REST APIs بسرعة.
- **سلامة البيانات العلائقية**: توفر قاعدة بيانات PostgreSQL ضمانات أمان المعاملات **ACID Compliance** والعلاقات بين المستخدمين والمسارات والمشاريع والتقييمات بأعلى كفاءة.
