## 🔭 المسارات التعليمية المستقبلية (Future Learning Tracks)

مع توسع المنصة في المراحل اللاحقة، ستتم إضافة مسارات تخصصية متقدمة:

1. **تطوير الواجهات الخلفية (Backend Engineering — Node.js & Go)**:
   - بروتوكول HTTP، بناء واجهات برمجة التطبيقات RESTful APIs، قواعد البيانات العلائقية وغير العلائقية، التخزين المؤقت Redis، وطوابير الرسائل Message Queues.
2. **تطوير التطبيقات الشاملة (Full-Stack Web Development)**:
   - بناء تطبيقات متكاملة، العرض من الخادم Server-Side Rendering (Next.js)، نظم المصادقة وحماية الجلسات، وأدوات الـ ORM.
3. **تصميم وهندسة واجهات وتجربة المستخدم (UI/UX & Design Engineering)**:
   - بناء أنظمة التصميم Design Systems، تحويل تصاميم Figma إلى كود، الحركات الدقيقة Micro-interactions، وتطبيقات متقدمة لإمكانية الوصول.
4. **عمليات التطوير والبنية السحابية (DevOps & Cloud Engineering)**:
   - أنظمة Linux، حاويات Docker، إدارة الحاويات Kubernetes، خطوط الأتمتة CI/CD، ومزودو السحابة (AWS, GCP).
5. **هندسة الذكاء الاصطناعي التطبيقي (AI Engineering)**:
   - دمج النماذج اللغوية الكبيرة LLMs، قواعد البيانات المتجهة Vector Databases، وأنظمة الـ RAG وسير عمل الوكلاء الذكية AI Agents.

## 📚 نموذج هيكل المناهج (Curriculum Hierarchy)

يتكون كل مسار تعليمي من 4 مستويات هرمية:

- **المسار (Path)**: التخصص المهني الشامل (مثل: *Frontend Engineering*).
  - **الوحدة (Module)**: موضوع تدريبي متكامل (مثل: *الوحدة 03: التعامل مع البيانات غير المتزامنة وواجهات برمجة التطبيقات Async & APIs*).
    - **الدرس (Lesson)**: شرح نظري وتطبيقي مركز للمفهوم مع أمثلة كود واضحة.
    - **التحدي البرمجي / مواصفات المشروع (Challenge / Project Brief)**: المهمة البرمجية العملية المطلوبة لاجتياز الوحدة.
